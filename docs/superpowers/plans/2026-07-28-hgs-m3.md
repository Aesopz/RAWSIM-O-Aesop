# HGS-M3 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax.

**Goal:** 建立 `GreedyM3GManager`（HGS-M3）——M3G 的貪婪啟發式對應：用 PVGS 已驗證的引擎，把派遣分數改成忠實的 M3G MINCORE 邊際（含 PipelineFloor shortfall 軟項），解空間 ⊆ M3G、貪婪小輸、可擴展到大案例。

**Architecture:** `GreedyM3GManager` 鏡像（複製）`PVGSManager`；`GreedyM3GConfiguration : PVGSConfiguration`（GetMethodType 回 GreedyM3G，路由到新 manager）。核心改動只在 DispatchLoop：(1) 硬 T cap（每站每 epoch 新派 pod ≤ T−future，future=inbound−processing）；(2) 派遣分數加 `+w_pipe·shortfall 減量` 軟項。不動 M1G/HADGS/SplitM2eIC/PVGS 四個既有 manager 檔。

**Tech Stack:** C# 7.3 / net48 / RAWSimO.Core；無 Gurobi。

## Global Constraints

- **Build x64 Release，PowerShell**：`MSBuild RAWSimOWithSolverWrapping.sln /p:Platform=x64 /p:Configuration=Release`（含 RAWSimO.CLI，刷新 DLL）。單專案 target 用底線：`/t:RAWSimO_Core`。不要用 Git Bash 跑 MSBuild。
- **不可動**：`M1GManager.cs` / `HADGSManager.cs` / `SplitM2eICManager.cs` / `PVGSManager.cs`（PVGS 維持乾淨 baseline，HGS-M3 用複製）。可動引擎註冊檔（enum/factory/XmlInclude/csproj）——PVGS 當初也這樣註冊。
- **C# 7.3**：新 `.cs` 手動加 `<Compile Include>` 到 `RAWSimO.Core/RAWSimO.Core.csproj`。out 參數不可被 lambda 捕獲。
- **公平原則（核心）**：HGS-M3 共用參數與 M3G MINCORE 逐一相同：CompletionWeight=40(=|w2|)、DistanceWeight=1(=w1)、PipelineFloorWeight=20、PipelineFloorLeadSec=70、PipelineFloorTarget=1、QueuedPodDrawPenalty=1、OnTheWayPodDrawPenalty=3。**不得為對齊 M3G 調參**。
- **future(s) 定義（關鍵，PVGS-DB 在此出錯）**：`future(s) = (inbound pods to s) − (processing pods at s)`，鏡像 M3G `icFutureByStation = icCommittedHere − icProc.Count`（`SplitM2eICManager.cs:607`）。**必須扣掉正在處理的 pod**，否則 T=1 退化成硬序列化 → 過攢（PVGS-DB 病）。
- **驗收指標**：footprint.csv `;` 分隔無 header：TP=col92、PO=col130、IPO=col122、turnover=col93；EOR 讀 statistics.txt `KPI_EOR:`。**M3G 基準 o100 2-seed：TP=290.5, PO=5.82, IPO=9.70, EOR=1.49, turnover~1496**。
- **標準場景**：o100/o200 = `small_o{100,200}_mu100_4h_inv70.xsett`，layout `small.xlayo`，2 seeds。CLI：`RAWSimO.CLI\bin\x64\Release\RAWSimO.CLI.exe <layout> <xsett> <xconf> <outdir> <seed>`。

```csharp
    /// HGS-M3: greedy heuristic counterpart of M3G (SplitM2eIC MINCORE), as HADGS is to M1G.
    /// Inherits PVGS's engine config; GetMethodType routes to GreedyM3GManager. Adds the

    /// dispatch score needs. Solution space is a subset of M3G by construction.
    /// </summary>
    public class GreedyM3GConfiguration : PVGSConfiguration
    {
        public override OrderBatchingMethodType GetMethodType() { return OrderBatchingMethodType.GreedyM3G; }
        public override string GetMethodName() { if (!string.IsNullOrWhiteSpace(Name)) return Name; return "OBGREEDYM3G"; }
        /// <summary>w_pipe: soft-objective weight per unit of per-station pipeline shortfall while the lead gate is open. Mirrors SplitM2eIC PipelineFloorWeight (20).</summary>
        public double PipelineFloorWeight = 20;
        /// <summary>Lead seconds for the pipeline gate. Mirrors SplitM2eIC PipelineFloorLeadSec (70).</summary>
        public double PipelineFloorLeadSec = 70;
        /// <summary>Target future (inbound-minus-processing) pods per station; hard anti-oversupply cap. Mirrors SplitM2eIC PipelineFloorTarget (1).</summary>
        public int PipelineFloorTarget = 1;
    }
```

### Task 2: GreedyM3GManager（複製 PVGSManager，改 DispatchLoop）

**Files:**
- Create: `RAWSimO.Core/Control/Defaults/OrderBatching/GreedyM3GManager.cs`（複製自 PVGSManager.cs）

**Interfaces:**
- Consumes: Task 1 的 `GreedyM3GConfiguration`、`OrderBatchingMethodType.GreedyM3G`；既有 `PvgsEpochState`(st.StationList, st.PodsAt, st.PodToBot)、`M2eICMath.PipelineGateOpen`、`OutputStation.GetInfoCurrentPodReleaseLeft()`、`ClassifyPodTier`（PVGS 內 tier 0=processing 分類）。

- [ ] **Step 1: 複製並改名**

複製 `PVGSManager.cs` → `GreedyM3GManager.cs`。全檔改：`class PVGSManager` → `class GreedyM3GManager`；建構子 `public PVGSManager(` → `public GreedyM3GManager(`；`_config` 的型別若為 `PVGSConfiguration`，改宣告/賦值為 `GreedyM3GConfiguration`（cast 來源 `instance.ControllerConfig.OrderBatchingConfig as GreedyM3GConfiguration`）。保留所有其他 helper 邏輯不變。

- [ ] **Step 2: DispatchLoop 加硬 T cap + shortfall 軟項**

在 `GreedyM3GManager.DispatchLoop` 的 per-station 迴圈（`for (int s ...)`，`if (st.FreeSlots[s] <= 0) continue;` 之後）插入 T cap 與 future 計算：
```csharp
                        // (HGS-M3) hard T cap: future(s) = inbound - processing (mirror M3G
                        // icFutureByStation = icCommittedHere - icProc.Count). Skip pulling a new
                        // pod when future >= T. thisEpochDispatched[s] counts pods this manager
                        // already dispatched to s this epoch (st.PodsAt is the epoch-start snapshot).
                        int gm_processing = st.PodsAt[s].Count(p => PodDrawTier(st, p, st.StationList[s]) == 0);
                        int gm_future = (st.PodsAt[s].Count - gm_processing) + thisEpochDispatched[s];
                        if (gm_future >= _config.PipelineFloorTarget)
                            continue;
```
在此迴圈開始前（DispatchLoop 頂部，`while` 之外）宣告並每 epoch 歸零：
```csharp
            int[] thisEpochDispatched = new int[st.StationList.Count];
```
並在**實際派出一台 pod 之後**（找到 `st.StationList[bestStation].RegisterInboundPod(bestPod);` 那行附近）加：
```csharp
                thisEpochDispatched[bestStation]++;
```
（`PodDrawTier(PvgsEpochState st, Pod pod, OutputStation station)` 為 PVGS 既有 `private static` 方法，回 0=processing/1=queued/2=on-the-way，見 PVGSManager.cs:351。）

- [ ] **Step 3: 派遣分數加 shortfall 軟項**

在 DispatchLoop 計算 `score`（E-mode `PvgsExactAligned.Score(...)` 與 legacy 兩處）之後、`if (score > bestScore)` 之前，加上 shortfall bonus：
```csharp
                        // (HGS-M3) faithful M3G marginal: add the PipelineFloor shortfall reward.
                        // Dispatching to s while its lead gate is open and future < T removes one
                        // unit of shortfall penalty (w_pipe). Soft objective term (NOT a hard gate)
                        // -> keeps the 2-pod pipeline / parallelism without over-serializing.
                        double gm_releaseLeft = st.StationList[s].GetInfoCurrentPodReleaseLeft();
                        bool gm_gateOpen = M2eICMath.PipelineGateOpen(
                            !double.IsNaN(gm_releaseLeft), gm_releaseLeft, _config.PipelineFloorLeadSec);
                        if (gm_gateOpen && gm_future < _config.PipelineFloorTarget)
                            score += _config.PipelineFloorWeight;
```
（`gm_future` 沿用 Step 2 算出的值；coverageFirst 分支本設計不使用，維持原樣即可——HGS-M3 config 不開 CoverageFirstScoring。）
