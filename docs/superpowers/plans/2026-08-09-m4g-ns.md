```csharp
    /// <summary>
    /// M4G-NS: the whole-order no-split control arm. Structurally M1G's assignment (one order,
    /// one station, all-or-nothing) with M4G's self-calibrated pricing substituted for M1G's
    /// hand-tuned w1/w2/w3.
    ///
    /// Inherits M1GConfiguration so every `is M1GConfiguration` type test in the engine passes
    /// without touching any engine file - the same trick SAM1GConfiguration and M4GConfiguration
    /// use.
    ///
    /// The price list is deliberately NOT IM4GPrices: this arm has no lambda (per line), no rho
    /// (per unit) and no epsilon (per unit), and the absence is enforced structurally rather than
    /// by configuration. See spec 2026-08-09 INV-2.
    /// </summary>
    public class M4GNSConfiguration : M1GConfiguration
    {
        /// <summary>Returns the type of the method.</summary>
        public override OrderBatchingMethodType GetMethodType() { return OrderBatchingMethodType.M4GNS; }

        /// <summary>Scales mu after it is measured. 1.0 = pure measurement, the intended setting.</summary>
        public double MuScale = 1.0;
        /// <summary>Scales delta after it is measured. 1.0 = pure measurement.</summary>
        public double DeltaScale = 1.0;
        /// <summary>Completed orders required before mu is measured rather than taken from MuFallback.</summary>
        public int WarmupOrders = 50;
        /// <summary>Warm-up metres per completed order, used until WarmupOrders is reached.</summary>
        public double MuFallback = 24.0;
        /// <summary>Warm-up realisation rate, used until WarmupOrders is reached.</summary>
        public double DeltaFallback = 0.05;
        /// <summary>Pins mu to a constant when &gt; 0 (diagnostics / ablation only).</summary>
        public double MuFixed = 0;
        /// <summary>Pins delta to a constant when &gt; 0 (diagnostics / ablation only).</summary>
        public double DeltaFixed = 0;
        /// <summary>Stratify delta by committed-pod count, same key M4G uses (min(|Pb|,3)).</summary>
        public bool StratifiedDelta = true;
        /// <summary>Minimum valued orders in a stratum before its own ratio is trusted.</summary>
        public int DeltaStratumMinOrders = 50;
        /// <summary>Dinkelbach iterations per decision. 0 = single solve at the measured mu.</summary>
        public int DinkelbachIterations = 5;
        /// <summary>Stop the Dinkelbach loop once |objective| falls below this.</summary>
        public double DinkelbachTolerance = 0.5;
        /// <summary>Max doublings of mu when the solve degenerates to "dispatch nothing".</summary>
        public int DinkelbachEscalations = 6;
    }
```

## Task 2 — `M4GNSPricing.cs`（逐字建立）

**Model：haiku**（完整程式碼已給定）

新建 `RAWSimO.Core/Control/Defaults/OrderBatching/M4GNSPricing.cs`，內容**逐字如下**：

```csharp
using System;
using System.Collections.Generic;
using RAWSimO.Core.Configurations;

namespace RAWSimO.Core.Control.Defaults.OrderBatching
{
    /// <summary>
    /// Price state machine for M4G-NS. Deliberately NOT a reuse of M4GPricing.
    ///
    /// M4G-NS's decision atom is the ORDER, so its price list may only contain order-denominated
    /// prices (spec 2026-08-09 INV-2). This class therefore has no lambda (metres per line), no
    /// rho (metres per unit) and no epsilon (metres per unit) - not "set to zero", but absent.
    /// You cannot accidentally price a line here, because the field does not exist. That is the
    /// point: the invariant is structural, not configured.
    ///
    ///   mu    = cumulative distance / cumulative completed orders     [m / order]
    ///   delta = cumulative bound completions / cumulative valued ones [0..1]
    ///
    /// mu is MEASURED directly. It is emphatically not lambda * lines-per-order, which is how
    /// M4G derives its mu - that derivation needs lambda, and lambda does not exist here.
    ///
    /// Pure state machine: never touches the solver, the instance or the file system.
    /// </summary>
    public class M4GNSPricing
    {
        private readonly M4GNSConfiguration _config;
        private int _completedOrders;
        private long _boundOrdersTotal;
        private long _valuedOrdersTotal;
        /// <summary>Per-stratum {bound, valued} order totals; only read when StratifiedDelta is on.</summary>
        private readonly Dictionary<int, long[]> _strata = new Dictionary<int, long[]>();

        /// <summary>Creates the pricing state machine.</summary>
        /// <param name="config">The owning manager's configuration.</param>
        public M4GNSPricing(M4GNSConfiguration config)
        {
            if (config == null) throw new ArgumentNullException("config");
            _config = config;
        }

        /// <summary>Cumulative number of orders completed so far.</summary>
        public int CumulativeCompletedOrders { get { return _completedOrders; } }
        /// <summary>Cumulative orders the binding layer completed, across all decisions.</summary>
        public long CumulativeBoundOrders { get { return _boundOrdersTotal; } }
        /// <summary>Cumulative orders the valuation layer completed, across all decisions.</summary>
        public long CumulativeValuedOrders { get { return _valuedOrdersTotal; } }

        /// <summary>Whether the running statistics are still too thin to price from.</summary>
        private bool InWarmup { get { return _completedOrders < _config.WarmupOrders; } }

        /// <summary>Metres per completed order. Measured, not derived.</summary>
        /// <param name="cumulativeDistanceMetres">Instance.StatOverallDistanceTraveled at decision time.</param>
        public double Mu(double cumulativeDistanceMetres)
        {
            if (_config.MuFixed > 0) return _config.MuFixed;
            if (InWarmup) return _config.MuScale * _config.MuFallback;
            return _config.MuScale * (cumulativeDistanceMetres / Math.Max(1, _completedOrders));
        }

        /// <summary>System-wide realisation rate.</summary>
        public double Delta() { return Delta(-1); }

        /// <summary>
        /// Stratum-conditioned realisation rate: of the orders the valuation layer scored complete,
        /// what share did the binding layer actually take. A stratum below DeltaStratumMinOrders
        /// falls back to the system-wide ratio, as does stratum &lt; 0 or StratifiedDelta off.
        /// </summary>
        /// <param name="stratum">Bucket key for this decision, min(|Pb|, 3) to match M4G.</param>
        public double Delta(int stratum)
        {
            if (_config.DeltaFixed > 0) return Math.Min(1.0, _config.DeltaFixed);
            double raw;
            if (InWarmup) raw = _config.DeltaFallback;
            else
            {
                long bound = _boundOrdersTotal, valued = _valuedOrdersTotal;
                long[] cell;
                if (_config.StratifiedDelta && stratum >= 0
                    && _strata.TryGetValue(stratum, out cell)
                    && cell[1] >= _config.DeltaStratumMinOrders)
                { bound = cell[0]; valued = cell[1]; }
                raw = (double)bound / Math.Max(1, valued);
            }
            return Math.Max(0.0, Math.Min(1.0, _config.DeltaScale * raw));
        }

        /// <summary>Records orders completed by this decision (mu's denominator).</summary>
        public void RegisterCompletedOrders(int count)
        { if (count > 0) _completedOrders += count; }

        /// <summary>Feeds one decision's bound/valued completion counts into delta's totals.</summary>
        public void RegisterDecision(int boundOrders, int valuedOrders)
        { RegisterDecision(boundOrders, valuedOrders, -1); }

        /// <summary>Stratified counterpart; stratum &lt; 0 updates only the system-wide totals.</summary>
        public void RegisterDecision(int boundOrders, int valuedOrders, int stratum)
        {
            if (boundOrders > 0) _boundOrdersTotal += boundOrders;
            if (valuedOrders > 0) _valuedOrdersTotal += valuedOrders;
            if (stratum < 0) return;
            long[] cell;
            if (!_strata.TryGetValue(stratum, out cell))
            {
                cell = new long[2];
                _strata[stratum] = cell;
            }
            if (boundOrders > 0) cell[0] += boundOrders;
            if (valuedOrders > 0) cell[1] += valuedOrders;
        }
    }
}
```

### 3.3 Snapshot 的需求欄位

```csharp
/// <summary>Order -> its FULL demand. M4G-NS has no partial fulfilment, so there is no residual
/// ledger: an order is either untouched or completely assigned (spec INV-1).</summary>
public Dictionary<Order, Dictionary<ItemDescription, int>> Demands
    = new Dictionary<Order, Dictionary<ItemDescription, int>>();

建構方式：對每個 pending order，`foreach (var p in order.Positions) Demands[order][p.Key] = p.Value;`

`PendingOrders` 的篩選條件：**該訂單的每一條線都必須有貨架覆蓋**（`snap.PiSKU.ContainsKey(sku)` 對所有 SKU 成立）才納入。理由：整單原子下，只要有一條線蓋不到，這張單本次就完全不可能被完成，納入只會製造無用變數。**這同時使 V-g 在多數情況下成為冗餘保險。**

### 3.5 限制式（**新程式碼，逐字照下列公式實作**）

以下 `Sum` 一律使用會對空序列拋例外的 `LinearExpression.Sum(IEnumerable<Variable>)`。**每一處呼叫前都必須有守衛，且守衛不可只是 `continue`**（見 3.6）。

**綁定層**（`gv` = g 變數，`yv` = y，`zv` = z）：

```
N1  ∀(i,p,s):   Σ_o g[o,i,p,s]  ≤  a_pi · x[p,s]
N2  ∀o,∀i:      Σ_p Σ_s g[o,i,p,s]  ==  d_oi · z[o]        ← 等式，NS 的全部語意
N3  ∀(o,s):     Σ_i Σ_p g[o,i,p,s]  ≤  (Σ_i d_oi) · y[o,s]
N4  ∀o:         Σ_s y[o,s]  ≤  1
N5  ∀s:         Σ_o y[o,s]  ≤  C_s
N6  ∀o:         z[o]  ==  Σ_s y[o,s]
```

**估值層**：以 `gh/yh/zh` 重複 **N1、N2、N3、N4、N6**，`AddConstr` 名稱加後綴 `h`（`"N1h"` …）。
**不加 N5。** 這是兩層唯一的結構差異。

**V-g（誠實完成獎勵）**：

B2  ∀(o,s):      y[o,s]      ≤  yh[o,s]

```

### 3.7 目標式與 Dinkelbach（**新程式碼**）

```csharp
double delta = _pricing.Delta(stratum);          // stratum = StratifiedDelta ? min(Pb.Count,3) : -1

// D 側：只有 Pa 付路程。逐字對應 M4G 的 T1/T2。
LinearExpression objective =
    LinearExpression.Sum(sym.Xps.Where(v => snap.Pa.Contains(v.pod))
        .Select(v => bin[v.name] * (M1GPodStationCost(v.pod, v.outputstation)
            + PodStationExtraCost(v.pod, v.outputstation))), wrapper)
  + LinearExpression.Sum(sym.Urp.Where(v => snap.Pa.Contains(v.pod) && v.pod.Waypoint != null)
        .Select(v => bin[v.name] * M1GBotPodCost(v.robot, v.pod)), wrapper);

// V 側：只有訂單完成，由 delta 劈成兩段。沒有 lambda、rho、epsilon 項。
var zBound  = snap.PendingOrders.Select(o => bin["z_"  + o.ID]).ToList();
var zValued = snap.PendingOrders.Select(o => bin["zh_" + o.ID]).ToList();
if (zBound.Count  > 0) objective = objective + LinearExpression.Sum(zBound)  * (-mu * (1.0 - delta));
if (zValued.Count > 0) objective = objective + LinearExpression.Sum(zValued) * (-mu * delta);

wrapper.SetObjective(objective, OptimizationSense.Minimize);
```

**D\* 回讀**：與 M4G 相同——只加總 `Xps`（Pa）與 `Urp`（Pa）中取值非 0 者的距離。

**Dinkelbach 迴圈**：鏡像 `M4GManager.cs:1660-1810` 的結構（含雙向升壓 `DinkelbachEscalations`），**但把 λ 換成 μ，且不需要任何比例縮放**——只有一個價格，`V` 的形狀恆定：

```csharp
double vStar = muK > 0 ? (result.DStar - result.Objective) / muK : 0.0;
if (vStar <= 0 && escalations < _cfg.DinkelbachEscalations && muK > 0)
{ escalations++; muK *= 2.0; /* 重解 */ continue; }
if (vStar <= 0) break;
if (Math.Abs(result.Objective) <= _cfg.DinkelbachTolerance) break;
double muNext = result.DStar / vStar;
if (muNext <= 0) break;
/* 以 muNext 重解；若 next 退化則保留前一個 result 並 break */
```

> 模型只建一次，每個新 μ 只重下目標式（限制式沒有一條參照 μ）。重解前必須 `wrapper.Reset()`，否則會從舊解暖啟動而靜默改變決策。

# 計畫增補 v2（2026-08-09，取代 Task 3 的模型設計）

## 為什麼要重做

v1 的 M4G-NS 自建了一套整單模型（`g[o,i,p,s]` ＋ N1–N6）。實測後審查發現**它不是「M1G + 定價」**：

1. **漏掉 M1G 的行為主宰 `w3 = 1000`**（每個空槽罰 1000 公尺，是訂單獎勵 40 的 25 倍）。
   M1G 靠這一項強制填滿槽位；v1 的 `Σ_o y[o,s] ≤ C_s` 是純不等式，完全沒有對應項。
   ⟹ v1 實際上是「M1G + 定價 − 護欄」，對照被第二個變數污染。
   （實測槽位影子價 = **8.51 公尺**，M1G 的 1000 高估約 **120 倍**。）

2. **M1G 本來就有兩層結構，v1 卻另外發明了一套。**
   `yos[o,s]`：受 shi2（一單一站）＋ shi5（貨架覆蓋），**不受槽位限制**，領 w2 獎勵 → **估值層**
   `yaos[o,s]`：`yaos ≤ yos`（shi3）＋ shi4（槽位容量），**真正被執行**（`M1GManager.cs:795-805`
   的 `_availableStationorder` 由 yaos 建立）→ **綁定層**
   ⟹ M1G 把估值層以全額 w2 計價，等於**隱含設定 δ = 1**。

**新原則：決策結構與 M1G 逐條相同，只把三個手調權重換成量測價格。**

## v2 模型

### 變數（M1G 的完整集合，名稱逐字相同）

| 名稱 | 型別 | 意義 |
|---|---|---|
| `"xps_" + pod.ID + "_" + station.ID` | binary | 貨架→站台 |
| `"yos_" + order.ID + "_" + station.ID` | binary | **估值層**：訂單可在該站被覆蓋 |
| `"yaos_" + order.ID + "_" + station.ID` | binary | **綁定層**：訂單真的佔一個槽位 |
| `"yrp_" + robot.ID + "_" + pod.ID` | binary | 機器人→貨架 |
| `"us_" + station.ID` | integer [0, maxSlots] | 該站閒置槽位數 |
| `"dops_" + order.ID + "_" + pod.ID + "_" + station.ID` | binary | 訂單自該貨架取貨 |

🚫 **不再有 `g` / `gh` / `z` / `zh`。** 件級變數完全不存在——INV-2／INV-3 因此由結構保證，
連「係數為 0」都不需要驗。

### 限制式：shi2–shi13，**逐條鏡像 `M1GManager.cs:714-771`，一字不改**

| 編號 | 式子 | 來源行 |
|---|---|---|
| shi2 | `Σ_s yos[o,s] ≤ 1` | 715 |
| shi3 | `yaos[o,s] ≤ yos[o,s]` | 719-720 |
| shi4 | `Σ_o yaos[o,s] == Cs[s] − us[s]`（**等式**） | 723 |
| shi5 | `Σ_o d_oi·yos[o,s] ≤ Σ_p a_pi·xps[p,s]`  ∀(sku, station) | 728-730 |
| shi6 | `Σ_s xps[p,s] ≤ 1` | 734 |
| shi7 | `xps[p,s] == 1`（已承諾貨架） | 741 |
| shi11 | `yrp[r,p] == 1`（已承諾機器人） | 742 |

> 鏡像失真才是缺陷。逐條對照來源行號，語意必須等價。

### 目標式（**唯一的改動**）

```
min   Σ_{p,s} D_ps·xps[p,s]  +  Σ_{r,p} D_rp·yrp[r,p]        ← w1=1，本來就只是公尺
      − μ(1−δ) · Σ_{o,s} yaos[o,s]                            ← 取代 w2 的綁定側
      − μδ     · Σ_{o,s} yos[o,s]                             ← 取代 w2 的估值側
      + σ      · Σ_s us[s]                                    ← 取代 w3 = 1000
```

- **δ = 1 時本式退化為 M1G 的 `w2·Σyos` 形式**——這是設計上的正確性檢查，v2 是 M1G 的嚴格推廣。
- **σ = SlotScale × μ**，`SlotScale` 預設 **1.0**：「讓一個槽位空著，代價等於一張訂單的價值」。
  零新增自由參數。`SlotScale = 0` 退化回 v1 行為，`SlotScale → ∞` 逼近 M1G 的強制填滿——
  **σ 因此把 v1、v2、M1G 參數化在同一條族線上**，是天然的消融軸。
- 成本側的 `.Where(...)` 過濾條件比照 M1G（`UnusedPods.Contains(u.pod)` 等），
  使沉沒貨架不重複計費。

### 價格結算

```csharp
_pricing.RegisterCompletedOrders(本次 yaos==1 的訂單數);
_pricing.RegisterDecision(boundOrders: Σyaos, valuedOrders: Σyos, stratum);
```
δ 的定義因此是「**綁定層真正佔槽的訂單 ÷ 估值層認為可覆蓋的訂單**」，與 M1G 的
`yaos ≤ yos` 結構完全對齊。

### 提交

由 **`yaos == 1`** 決定 `AllocateOrder(order, station)`，鏡像 `M1GManager.cs:795-805`。
🚫 仍然不建立拆單子單、不寫 splitorders.csv。

### 設定新增

`M4GNSConfiguration` **末端追加**：
```csharp
/// <summary>Idle-slot price as a multiple of mu. 1.0 = "an empty slot costs one order's
/// worth of value". Replaces M1G's hand-set w3 = 1000, which the measured slot shadow
/// price (8.51 m) says over-prices a slot by roughly 120x. 0 disables the term.</summary>
public double SlotScale = 1.0;
```
xconf 對應追加 `<SlotScale>1</SlotScale>`（放在最後一個元素之後）。
