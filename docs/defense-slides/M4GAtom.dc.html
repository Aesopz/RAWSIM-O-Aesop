增量 ① · 決策原子
由「訂單」降到「件」—— 以及隨之浮現的結構後果
M1G
yos ∈ {0, 1}
原子＝訂單。一張單只能整批、單站、當期指派。
M4G
qoips ∈ ℤ≥0
原子＝件。訂單 o 的 SKU i 由貨架 p 於站台 s 取幾件 — 跨站、跨期、多貨架皆可。
兩層各自的變數集合
估值層（帶帽）
q̂oips 估值取件量
ĉoi 訂單行 (o,i) 已被取滿
ẑo 訂單 o 全部行皆關閉
綁定層
qoips 實際取件量
yos 訂單 o 於站台 s 佔用一個槽位
coi, zo 綁定的行關閉與訂單完成
xps, yrp 貨架與機器人指派（與 M1G 相同，TA 仍在模型內）
限制式的對應改寫
shi2 → （移除） 一單一站的限制取消；拆單即由此浮現，而非新增功能
shi5 → V1–V3 整單覆蓋不等式，拆成逐 (SKU, 貨架, 站台) 的取件上限與逐行的關閉條件
— → V4 / B7 新增完成變數。容許部分滿足後，「指派」不再蘊含「完成」，故 c、z 必須存在
shi3 → B1 綁定 ≤ 估值，由訂單層級改為逐件：q ≤ q̂
shi4 → B3 Σo yos ≤ Cs — 等式改為不等式，空槽不再被強制填滿
shi6–shi11 → R1–R5 貨架/機器人/承諾繼承的限制式語意不變，僅重新編號
槽位仍以訂單計。拆到兩個站台就佔用兩個槽位（B2/B3）— 這是同期跨站拆單罕見的結構性原因，非模型缺陷。
