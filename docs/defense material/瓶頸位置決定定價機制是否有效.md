# 瓶頸位置決定定價機制是否有效

**適用問題**
- 為什麼要用自我校準的動態定價，而不是 M1G 那種固定權重？
- 你的定價方法在什麼條件下有效？換一個設定還成立嗎？
- 拆單與定價兩個機制的關係是什麼？

**一句話**
> 比值定價（min D/V）只在**被計價的資源就是系統瓶頸**時有效。
> 拆單把瓶頸從「站台等貨架」移到「機器人行程」，因而使定價進入有效區間。

---

## 1. 結論

同一套定價機制，在兩種拆單粒度下**排序完全顛倒**：

| | 拆單（行級） | 不拆單（訂單級） |
|---|---|---|
| **動態定價**（自我校準 + Dinkelbach） | **最佳** 1430 件 | **最差** 1158 件 |
| 固定權重（M1G 量級） | 1393 件 | **最佳** 1275 件 |
| 固定權重（歷史平均值） | 1388 件 | 1238 件 |
| M1G | — | 1224 件 |

決定排序的不是定價方法本身，而是**系統瓶頸在哪裡**：

```
拆單     站台供給落差 0.44%    站台已飽和 → 瓶頸在機器人行程 → 計價對象正確
不拆單   站台供給落差 19.27%   站台餓著等貨架 → 瓶頸在站台 → 計價對象錯誤
```

---

## 2. 數據

單一 seed、2 小時、`small_6bot` layout（6 台機器人、2 個揀貨站、站台容量 6）。
完整數值見 `data/bottleneck_shift_seed0_2h.csv`。

### 2.1 拆單模型：動態定價最佳

| 指標 | 動態定價 | 固定（歷史均值） | 固定（M1G 量級） |
|---|---:|---:|---:|
| 完成件數 | **1430** | 1388 | 1393 |
| pile-on | **5.89** | 4.79 | 4.99 |
| EOR (kJ/單) | **1.10** | 1.30 | 1.33 |
| 總距離 (m) | **8460** | 9684 | 10242 |
| 貨架到訪次數 | **102** | 124 | 121 |
| **站台佔用率** | **99.29%** | 96.33% | 96.65% |
| **站台供給落差** | **0.44%** | 3.32% | 2.94% |
| 每次到訪服務單數 | **9.18** | 7.19 | 7.17 |

兩種固定權重表現彼此接近（件數差 0.4%），**都遜於動態**。
所以差異不來自「價格水位選得好不好」，而來自**是否隨狀態調整**。

M1G 量級的大權重在此還付出額外代價：多走 **21%** 的距離（10242 vs 8460），
只換到 1 張訂單——因為站台已經飽和，多花的行程換不到產出。

### 2.2 不拆單模型：排序顛倒

| 指標 | 動態定價 | 固定 μ=18.29 | 固定 μ=1040 | 固定 μ=1500 | M1G |
|---|---:|---:|---:|---:|---:|
| 完成件數 | **1158** | 1238 | 1275 | **1287** | 1224 |
| 完成訂單 | 554 | 583 | 601 | **611** | 578 |
| pile-on | 3.06 | 3.53 | **3.69** | 3.49 | 3.27 |
| EOR (kJ/單) | 1.66 | 1.57 | **1.52** | 1.65 | 1.64 |
| 總距離 (m) | 11402 | **11146** | 11328 | 12519 | 11581 |
| 貨架到訪次數 | 179 | 163 | **161** | 173 | 175 |
| **站台佔用率** | **80.40%** | 85.92% | 88.47% | **89.33%** | 84.94% |
| **站台供給落差** | **19.27%** | 13.72% | 11.17% | **10.32%** | 14.70% |
| 每次到訪服務單數 | 3.99 | 4.59 | **4.83** | 4.51 | 4.20 |

**價格越高，站台佔用率與吞吐單調上升**（80.4% → 85.9% → 88.5% → 89.3%）。
動態定價把價格往下修，因此落在最差的一端。

μ 從 1040 提高到 1500 是吞吐與效率的**轉折點**：多做 12 件（+0.9%），
代價是多叫 12 台貨架、多走 1191 公尺、EOR 惡化 8.6%。
即不拆單模型下，**吞吐與能耗是對立的**。

### 2.3 吞吐完全由站台佔用率決定

八組配置的站台佔用率與完成件數**單調對應，無例外**：

```
佔用率   80.40%  84.94%  85.92%  88.47%  89.33%  96.33%  96.65%  99.29%
件數      1158    1224    1238    1275    1287    1388    1393    1430
```

而「揀完一件所需的站台秒數」是物理常數，八組皆為 9.2–9.7 秒。
因此 **吞吐 = 站台可用時間 × 佔用率 ÷ 每件秒數**，佔用率是唯一的可控項。

### 2.4 站台閒置全部是「等貨架」

站台閒置在模擬中分成兩型：

- **Type A 供給落差**：還有事可做（有在途貨架／已指派訂單／積壓單），但貨架還沒到
- **Type B 無單可做**：真的沒有任何工作

實測八組配置的 **Type B 全部為 0**。所有閒置都是 Type A。
站台從來不缺訂單，只缺貨架。

## 3. 原理

### 3.1 比值目標式偏好「便宜但少」

目標式為 `min D − λP`，Dinkelbach 每期把 λ 收緊到當前快照可達的最佳比值 `min D/P`。
其效果是在候選方案中挑**比值最好**的，而非**絕對產出最大**的。

同一個決策快照下的兩種選擇：

```
方案甲   付 96 公尺派 4 台貨架  →  綁 12 張訂單     比值 8.0 公尺/單
方案乙   付 13 公尺派 1 台貨架  →  綁  6 張訂單     比值 2.2 公尺/單
```

比值定價選乙（比值好 3.6 倍），絕對產出只有甲的一半。

### 3.2 這在瓶頸為機器人時正確，在瓶頸為站台時錯誤

```
瓶頸是機器人行程   花掉的資源稀缺 → 應該追求 CP 值 → 比值定價正確
瓶頸是站台時間     花掉的資源充裕 → 應該追求絕對產出 → 比值定價錯誤
```

不拆單模型下，站台 **19.27%** 的時間餓著等貨架，而機器人在 **67%** 的決策中至少有一台閒置。
此時精打細算機器人的公尺數，代價是讓稀缺的站台更餓。

### 3.3 拆單改變了瓶頸位置

一台貨架在拆單模型中可以補**任何訂單的任何一條行**，因此它到站後能持續產出；
在不拆單模型中它只能湊**完整的整張訂單**，湊不齊就閒置。

```
                每次到訪服務單數   每次到訪揀貨秒   到訪次數   供給落差
拆單                 9.18          135.4          102      0.44%
不拆單               4.0–4.8       59–74          161–179   10–19%
```

拆單讓每台貨架待在站上的時間變成 2 倍，到訪次數降到 6 成，
站台幾乎不再有等待貨架的空檔——**瓶頸因而從站台移到機器人行程**。

### 3.4 M1G 的大權重是對這個成因的補償

M1G 的目標式為 `min w1·Σ距離 + w2·Σyos + w3·Σus`，其中 `w1=1, w2=−40, w3=1000`。
由於 `shi4` 為等式（`Σyaos = C_w − us`），空槽懲罰在代數上等價於綁定獎勵：

```
綁定訂單領 1000 + 40 = 1040 公尺        ⟹ 隱含 μ = 1040 公尺/訂單
僅估值領            40 公尺             ⟹ 隱含 β = 40/1040 = 0.0385
```

在平均每張訂單只需 20 公尺的系統裡把訂單標價成 1040 公尺，高出真實成本 50 倍。
**這不是估價，是用一個壓倒性的常數把「填滿槽位」變成事實上的硬約束**——
也就是對「站台飢餓」這個目標式看不見的成本所做的補償。

拆單消除了那個成本（供給落差 19.27% → 0.44%），補償也就不再必要，
價格得以回到真實量級（μ ≈ 13）。

## 4. 口委問答

**Q：既然固定權重在不拆單時比較好，為什麼不在拆單模型也用固定權重？**

測過了。拆單模型下兩種固定權重（歷史均值與 M1G 量級）都遜於動態定價，
件數各差 −2.94% 與 −2.59%，pile-on 差 −18.67% 與 −15.31%。
且兩者彼此接近（件數差 0.4%），代表差異來自「是否隨狀態調整」，不是價格水位。

**Q：你的方法只在拆單時有效，是不是很脆弱？**

有效條件是可陳述、可量測的：**被計價的資源是否為系統瓶頸**。
診斷量為站台供給落差率（拆單 0.44%、不拆單 19.27%），從模擬輸出直接讀取。
方法的適用範圍不是事後歸納，而是由瓶頸位置決定，且拆單本身就是移動瓶頸的機制。

**Q：M1G 的權重是調出來的，你的是量出來的，但你怎麼證明量測比較好？**

在拆單模型下，量測價格 + 動態調整的表現優於 M1G 量級的固定權重（件數 +2.59%、
EOR −16.7%、距離 −17.4%）。更重要的是 M1G 的 `w2=−40`、`w3=1000` 是為特定
設定挑選的，沒有推導依據也沒有轉移證據；本方法的價格由系統自身的歷史量測得出，
不需要為新設定重新調整。

**Q：拆單與定價哪一個才是貢獻？**

兩者有先後條件，不是並列。拆單改變瓶頸位置，使比值定價進入有效區間；
定價則管理拆單帶來的自由度，避免自由度變成浪費。
單獨採用任一機制都不能得到最佳結果——這由 2×2 的排序顛倒直接證實。
