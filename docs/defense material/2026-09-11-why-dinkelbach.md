# λ 是什麼、Gurobi 與 Dinkelbach 各做什麼、為什麼常數不行

**M4 定價機制的機制說明與實證**

2026-09-11 · small layout · 6 bots · 2 揀貨站 · 7200 s

---

## 0  一句話版本

> 我們要的是 `min D/P`（每關一行跑幾公尺），但分式 MIP 不能直接解。
> Dinkelbach 把它轉成**找一個純量的根**：定義 `F(λ) = min(D − λP)`，
> 則 `F(λ) < 0` 若且唯若 `λ > λ*`，而 `F(λ) = 0` 對整段 `λ ≤ λ*` 都成立（見 §2.0）。
> Gurobi 負責在給定 λ 下找最佳方案並回報目標值；Dinkelbach 讀取回報並修正 λ。
> **λ 不是我們挑的價值觀，是問題本身決定的量。**

---

## 1  分工

| 角色 | 做什麼 | 不做什麼 |
|---|---|---|
| **Gurobi** | 給定 λ，求 `min D − λP` 的最佳方案，回報目標值 | 不知道 `D/P` 的存在 |
| **Dinkelbach** | 讀取回報，更新 `λ ← D*/P*` | 不解任何最佳化問題 |

兩者都不完整，合起來才解得了分式問題。**這是為什麼不能只用一個求解器。**

目標值的意義：

```
D* − λ P* < 0   這個方案的實際成本低於你用 λ 估給它的價值
                ⟹ 你把一行定得太貴了 ⟹ 降價
```

---

## 2  核心定理

```
設  λ* = min over feasible x of  D(x) / P(x)，由 x* 達成

則  D(x*) − λ* P(x*) = 0
且  對所有可行 x：D(x) − λ* P(x) ≥ 0

⟹ x* 是 min(D − λ*P) 的最佳解，最佳值為 0
```

### 2.0 ⚠️ F 的正確刻畫：`F(λ) = 0 ⟺ λ ≤ λ*`

```
λ < λ*   所有 P>0 的方案皆 D/P ≥ λ* > λ ⟹ D − λP > 0；空任務給 0 ⟹ F(λ) = 0
λ = λ*   x* 給 0，空任務給 0                                   ⟹ F(λ*) = 0
λ > λ*   x* 給 P*(λ* − λ) < 0                                  ⟹ F(λ) < 0

⟹ F(λ) = 0 ⟺ λ ≤ λ*     （**不是** λ = λ*）
⟹ F(λ) < 0 ⟺ λ > λ*
```

**λ\* 以下整段區間 F 恆為 0**——這正是一側搜尋的來源：低於 λ\* 時沒有任何梯度資訊。
只有 `F(λ) < 0` 這個事件能證明 `λ > λ*`。

**在正確的 λ 上解線性問題，得到的就是分式問題的最佳解。**
線性化沒有近似任何東西——它在 λ\* 上是嚴格等價的。

### 2.1 ⚠️ 等價**只在 λ\* 上**成立

```
λ = λ*    argmin(D − λ*P) 的每個非空解都滿足 D/P = λ*    ⟹ 同解
λ ≠ λ*    argmin(D − λP) 通常是另一個方案                ⟹ 你解的不是 D/P
```

**這正是為什麼非迭代不可。** 如果任意 λ 都等價，隨便挑一個就好——固定 λ 也就成立了。
**等價的條件本身，就是固定 λ 失敗的原因。**

### 2.2 不是同步解兩個問題

```
我們從頭到尾只解   min D − λP     線性 MIP，Gurobi 做得到
從來沒有直接解     min D/P        分式 MIP，一次都沒解過
```

`F(λ)` 是**證書函數**，不是優化對象；我們要的是它的**根**。

---

## 3  更新規則就是 Newton 法

```
Newton：   λ_{k+1} = λ_k − F(λ_k) / F'(λ_k)
包絡定理： F'(λ) = −P(x_k)

代入：     λ_{k+1} = λ_k + [D(x_k) − λ_k P(x_k)] / P(x_k)
                   = D(x_k) / P(x_k)
```

**`λ ← D*/P*` 不是啟發式，是對 `F` 的 Newton 迭代，超線性收斂。**
每一次迭代解的是線性問題，總共只需幾次。

---

## 4  空計畫可行，帶來三個後果

我們的可行域永遠包含「什麼都不做」（`D = 0, P = 0`，目標值 = 0）。

### 4.1 目標值恆為非正

```
min(D − λP) ≤ 0  恆成立
⟹ 「目標值 > 0 的方案」不會被選中，也不存在用它調匯率的選項
⟹ 即使有一個很虧的方案，模型也只會選空任務
```

### 4.2 λ 只降不升

```
目標值 < 0 ⟹ D*/P* < λ_k ⟹ λ_next < λ_k
目標值 = 0 且 P > 0 ⟹ 損益兩平，λ = λ*，收斂
目標值 = 0 且 P = 0 ⟹ 空任務最佳，無 D*/P* 可算，無資訊
```

程式碼註解實測：**880 次下調，零次上調**。

### 4.3 因此起點必須在 λ\* 之上

若起點低於 λ\*，空任務最佳、`P = 0`、算不出 `λ_next`，就卡住。
**這就是上界跳躍存在的理由**——用一次窮舉找出「最便宜的、能關掉一行的單趟」作為可證明上界。

### 4.4 附帶：在 λ\* 上空任務與最佳方案必然平手

```
F(λ*) = 0
空任務     D = 0, P = 0  ⟹ 目標值 = 0
最佳方案   D/P = λ*      ⟹ 目標值 = 0      兩者同值
```

所以**恰好收斂到 λ\* 的那一刻，求解器可能回傳空任務**，把好方案丟掉。

### 4.5 試解退化是最佳性證書，不是「跨過頭」

序列永遠不會跨過 λ\*：

```
① λ_next = D*/P* 是某個可行方案「達成」的比值  ⟹ λ_next ≥ λ*
② 試解退化 ⟹ F(λ_next) = 0 ⟹ λ_next ≤ λ*
────────────────────────────────────────────
⟹ λ_next = λ*，且 x_t 滿足 D_t/P_t = λ* ⟹ **x_t 就是 D/P 的最佳解**
```

且「試解退化且 λ_next > λ\*」不可能發生——若 λ_next > λ\* 則 F(λ_next) < 0，
試解會回傳 P > 0 的負目標值方案。**退化這個事件本身就排除了未抵達的可能。**

因此 `trial P ≤ 0 → keep previous λ and solution` 不是防守措施，
是**最佳性證書的偵測器**；保留上一個方案不是退而求其次，是因為它已經最佳。

⚠️ 前提是求解器回傳真正的最佳解。有 MIP gap 時證書只是近似
（小規模 gap = 0 嚴格成立；大規模 1 小時仍有 9.25% gap，不成立）。

#### 實證（2026-09-11，正典 6 bots seed 0，984 次決策）

為了區辨兩種解釋，在守門觸發處記錄被拒的 `λ_next` 與試解的目標值
（`guardLamNext` / `guardTrialObj` 兩個診斷欄位，純記錄、不回饋）：

| | 次數 | 佔比 |
|---|---:|---:|
| 守門觸發（出口④） | 95 | 9.65% |
| 　試解目標值 \|obj\| ≤ 0.5 —— **平手於 λ\*** | **95** | **100.0%** |
| 　試解目標值 > 0.5 —— 空計畫嚴格勝出（未達 λ\*） | 0 | 0.0% |

被拒的 `λ_next` 範圍 0.57 – 22.62，**試解目標值全部恰為 0.000000**。

> **結論：空計畫從未嚴格勝出，只是平手。序列從未跨過 λ\*。**

⚠️ 程式碼註解（`M4GManager.cs:2818-2827`）把成因寫成「整數性造成 overshoot」。
**症狀描述正確**（無守門時整場模擬崩到 ~0 訂單，有實測），**但成因歸因錯誤**——
真正的成因是 §4.4 的平手，而採用平手的空計畫會把該期派車全部歸零。
註解待修正。

## 5  「正確的價值觀」有一個可檢查的定義：自洽

可達成的匯率是**實例的物理性質**，由佈局、訂單組成、貨架分布決定，與你相信什麼無關。

實測（6 bots，seed 0，固定 λ + 逃脫機制）：

| 相信的 λ | 實際執行比值 | 自洽比 |
|---:|---:|---:|
| 1.5 | 13.72 | 9.15× |
| 2.5 | 14.44 | 5.77× |
| 4.5 | 13.07 | 2.90× |
| 8.0 | 12.02 | 1.50× |
| 16 | 11.39 | 0.71× |
| 24 | 11.19 | 0.47× |

> **相信的 λ 橫跨 16 倍，實際執行出來的比值全部落在 11–14。**

自洽點（相信 = 執行）落在 **11–12** 之間。任何偏離它的價值觀，都會被系統的回應打臉，
而且是**可量測的**打臉：

- λ = 1.5：相信一行值 1.5 公尺，實際每行花 13.7 公尺 → 嚴重低估 → 什麼都不想做
- λ = 24：相信 24 公尺，實際只花 11.2 → 高估 → 接受不必要的爛趟次

**所以不需要「確保價值觀正確」，只需要讓它自我修正到自洽為止**，而 Newton 保證這件事收斂。

## 6  固定 λ 為什麼不行

### 6.1 它優化的是另一個函數

```
固定 λ = c ⟹ 求的是 min(D − cP) 的最佳解
             那通常不是 min(D/P) 的最佳解

c > λ*   高估線的價值 ⟹ 接受比可達成比值更差的趟次
c < λ*   低估 ⟹ 空任務最佳 ⟹ 什麼都不做
```

不是「找不到最佳 D/P」，是**根本沒在找 D/P**。

### 6.2 而 λ\* 每期都不同

λ\* 是**快照的函數**——哪些貨架在站上、哪些單待處理、哪台車空著，每期都不一樣。

正典 M4G 逐期收斂值（6 bots，5 seeds，僅有派車的決策）：

| 群 | 佔比 | 最小 | p25 | 中位 | p75 | 最大 |
|---|---:|---:|---:|---:|---:|---:|
| Newton 收斂 | 67.2% | 0.63 | 2.66 | **3.51** | 4.19 | 11.04 |
| 上界跳躍 | 32.8% | 10.00 | 16.00 | **19.00** | 26.00 | 43.00 |

```
Newton 群內變動        17 倍
含跳躍群的整體變動     68 倍
```

> **一個常數不可能等於一個每期變動 17 到 68 倍的量。**
> 即使用 35 次離線掃描調出「平均而言最好」的常數，它在任何**單一**決策上幾乎必然是錯的。

## 7  兩段式定價：兩個都是量測值

跳躍觸發時，歷史價格被當前快照的邊際成本取代。**但兩者都是量測值，都不是選定常數。**

| | 定義 | 意義 |
|---|---|---|
| `λ₀ = T^cum / L^cum` | 累計揀貨距離 ÷ 累計關閉行數 | **歷史平均成本** |
| `λ̄ = 快照窮舉` | 最便宜的、能關掉一行的單趟 | **當前邊際成本** |

```
λ₀ 夠高（P > 0）  ⟹ 不跳，用歷史價格，Newton 溫和修正   67.2% 的派車
λ₀ 太低（P ≤ 0）  ⟹ 跳，改用當前邊際成本                32.8% 的派車
```

**經濟意義**：歷史平均成本仍可達成時用它定價；現況比歷史差（沒有便宜趟次可做）時，
改用當前的邊際成本定價。**跳躍不是補丁，是這套定價規則的另一半。**

### 7.1 跳躍後 Newton 從不走回來，而且是結構必然

實測：180 次跳躍中，迭代次數**全部是 1**。原因可證明：

```
λ̄ 的定義 = 使「最便宜的有效單趟」剛好划算的最低價格
⟹ 任何低於 λ̄ 的價格，那一趟就不划算
⟹ Newton 提議的 λ_next 必然使試解退化
⟹ 守門條款必定觸發，保留 λ̄
```

## 8  λ 的因果作用域只有「派車與否」

```
目標式    min D − V,   V = λ[Σe + βΣ(ê−e)] + μ[Σf + βΣ(f̂−f)]
而        μ = λ (L^cum / N^cum)

⟹ V = λ · { 與 λ 無關的括號 }
```

當期沒有新派車 ⟹ `D = 0` 對所有候選方案成立 ⟹ 目標式 = `−λ·(括號)`
⟹ **argmin 與 λ 無關**（λ > 0，純正純量可提取）。

**所以只填單的決策上，λ 不具備任何改變排序的能力。**

實測佐證：

```
正典 M4G 6 bots，3387 次決策
  dinkIters = 0 的比例    83.1%      ← D* = 0，無事可定價，迴圈立刻退出
  有派車的決策比例        約 11–12%  ← λ 真正發揮作用的範圍
```

⚠️ 精確化：λ 仍然決定**要不要派車**這條邊界（比較 `D > 0` 與 `D = 0` 的方案）。
一旦這期決定不派車，λ 在剩餘選項之間才是惰性的。

## 9  完整的流程

```
問題       min D/P              沒有自由參數，但分式 MIP 不可直接解
  ↓
轉為找根   F(λ) = min(D − λP)，F 遞減且恆非正；F(λ) < 0 ⟺ λ > λ*
  ↓
Gurobi     給定 λ，回報該價格下的最佳方案與目標值
           目標值 < 0 ⟹「這方案比你相信的還划算」
  ↓
更新       λ ← D*/P*            Newton 法，必然下調
                                （因空任務可行 ⟹ 目標值恆 ≤ 0）
  ↓
守門       在 λ_next 試解        確認沒有跨過或剛好命中 λ*
  ↓
起點保證   上界跳躍              確保起點在 λ* 之上，否則無資訊可用
  ↓
結果       λ 收斂到當期快照的自洽匯率，並據此決定派不派、派哪一趟
```

**固定 λ 拿掉的是整個中間段**：沒有回報、沒有更新、沒有收斂，
只是把一個外生的數字直接當門檻用。

## 10  可以宣稱與不能宣稱

### 可以

- **λ 不是建模選擇，是解法的產物。** `λ* = min D/P` 完全由可行集合決定，沒有人挑它。
- **線性化無近似損失。** 在 λ\* 上嚴格等價，且 Newton 保證收斂。
- **正確性有可檢查的定義：自洽。** 實測顯示相信值差 16 倍、執行比值仍落在 11–14。
- **λ\* 每期變動 17–68 倍**，常數不可能追蹤。此論證不依賴任何對照實驗。
- **兩段式定價的兩個價格都是量測值**，目標式仍無選定常數。

### 不能

- **不能說「同時求解 D/P 與 D−λP」。** 我們從未解過 D/P。
- **不能說任意 λ 下兩者等價。** 只在 λ\* 上成立。
- **不能說 λ 影響所有決策。** 83% 的決策 λ 是惰性的（尺度不變）。
- **⚠️ 暖機期有選定常數。** `WarmupLines=50`、`LambdaFallback=10`、`DeltaFallback=0.05`、
  `LinesPerOrderFallback=2.4`。「目標式無選定常數」嚴格說只在**穩態**成立。
  敏感度實驗（`m4g_wu_lf5/lf20/w25/w100`）已建立，尚未執行。
- **⚠️ 兩個口徑的裂縫。** `λ₀ = T/L ≈ 2.5`（系統層級，含 81% 免費取得的行）
  與邊際派車比值 ≈ 11–14 相差 4–5 倍。兩者都是量測值，但量的是不同的東西。
  這正是跳躍在 32.8% 的派車上觸發的原因，需要在方法章單獨說明。
