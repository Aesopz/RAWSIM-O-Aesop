# Defense Material

口試問答用的邊界研究說明文件。

這個資料夾放的是**方法的適用範圍、失效條件、以及成因解釋**——也就是口委最可能追問、
而論文正文不會展開的那一類問題。每份文件只陳述**結論、數據與原理**，不記錄探索過程。

實驗過程、失敗路徑、程式改動記錄在 `docs/` 下的其他文件與 git history，不放這裡。
